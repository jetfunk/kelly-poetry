# Kelly 的詩詞 — 2019–2025 全量展開 Implementation Plan（Phase 4）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 將 Kelly 的詩詞網站從 2014–2018 擴展到 2019–2025（探勘候選 113 檔，去重與排除後約 105–108 首淨新增），每首配一張淡彩水墨意境圖，並部署上 GitHub Pages。

**Architecture:** 沿用已驗證的純靜態資料驅動架構（`index.html`＋`poem.html`＋`data/poems.json`＋`assets/js/main.js`）。新詩資料由解析器批次產生，圖片由 jet-comfyui（Z_Image Q8）批次生成，全部併入既有 `poems.json`，網站 code 原則免改（年份導航與「全部」視圖為 data-driven，自動涵蓋 2019–2025）。

**Tech Stack:** Python（解析/清洗/驗證，沿用 `tools/temp_parse_poems.py`、`tools/temp_clean_bodies3.py`、`tools/temp_verify_batch.py`、`temp_output/images3/run_pipeline.py`）、ComfyUI Z_Image Q8（`http://127.0.0.1:8188`，需確認在線）、gh CLI（GitHub Pages 部署）。

**前置狀態：** 網站已部署 GitHub Pages（`jetfunk.github.io/kelly-poetry`）。`data/poems.json` 現含 400 首（既有 188 樣板＋2014–2018＋散落 nodate），回歸測試（`tools/temp_nav_test.py`、`temp_gh_test.py`）期望值 400 全過。探查完成（`tools/temp_probe_2019_2025.py`、`temp_output/probe_2019_2025.json`）：**113 檔候選**，判定後年份分布 2019:43、2020:25、2021:23、2022:6、2023:10、2024:1、2025:3、2018:2（錯置）。

## Global Constraints

以下要求**逐字生效**，每個任務都隱含遵守：

- 所有溝通、註解、文件一律使用繁體中文（zh-TW）。
- 所有暫時性／測試用檔案與資料夾命名須含 `test` 或 `temp` 關鍵字。
- 詩作 id 格式：`YYYYMMDD-詩名`（日期內無破折號），id 用於圖片路徑 `assets/images/poems/<id>.jpg`，路徑經 `encodeURIComponent`。
- 圖片規格：1280×848（3:2）、真實 JPEG（magic `ffd8`）、淡彩水墨＋暖紙質感風格。
- 圖片 prompt 後綴固定：`, soft watercolor Chinese ink painting, warm cream paper texture, gentle light, serene, <emotion>`（emotion 從允許表選）。
- **不配樂**：本計畫不生成任何音檔。
- 年份判定：**以檔名前綴日期為準**（含資料夾內異年錯置檔，如 `2020\20190831-…`、`2021\20200912-…` 依檔名日期歸年）；無日期者歸入所在資料夾年份，標記 `date: ""`。
- 排除：非 Kelly 原創（作者線索：席慕容／席慕蓉／余光中／林徽因／鄭愁予）、歌詞改編（`我作的詞`、`原曲-*` 資料夾，不在候選範圍，勿引入）、編碼損壞無法解讀者。
- 重複檔去重：同（date, title）多份保留 body 最長者；與既有 400 首同 id 者跳過不重做（已確認重疊：`20180330-水映畫染`、`20190803-幾度夕陽紅`、`20220205-冬盡春來`、`20250216-春`）。
- **既有 400 首資料與圖片為已知正確，不得刪除或改動其 body/note/圖。**
- ComfyUI 需在 `http://127.0.0.1:8188` 在線；生成用 Z_Image Q8 workflow（`C:\Users\user\.claude\skills\jet-comfyui\references\comfyui\Z_Image文生图（gguf-Q8）.json`）。
- **驗證命令對 body 比對時，直接對 `p['body']` 字串做 regex**，勿用 `'\n'.join(...)`（Phase 2/3 教訓）。
