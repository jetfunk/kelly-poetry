```

├── index.html            ← 首頁：暖紙風年份導航 + 精選詩作卡片
├── poem.html             ← 詩作詳情頁（讀取 ?id= 參數渲染）

```

## 5. 圖片生成流程（jet-comfyui）

1. 解析詩作 txt → 自動偵測編碼（Big5 / UTF-8 / UTF-8-BOM）轉為 UTF-8
2. 依詩意撰寫英文提示詞，統一風格後綴（淡彩水墨插畫、暖紙感）
3. 使用 `generate_images.py`：
   - 首選 workflow：`Z_Image文生图（gguf-Q8）.json`（8GB VRAM lowvram 最穩）
   - 若品質不佳，改用 `ERNIE-Image-Turbo+文生图.json`
   - 先測試 1 張確認品質，再批次生成 8 張
   - 解析度：橫式 `1280×853`（3:2），符合詳情頁大圖版面
4. 生成圖儲存為 `assets/images/poems/<id>.jpg`

## 6. 音樂生成流程（jet-audio.cpp / ACE-Step 1.5）

1. 依每首詩意境撰寫音樂 prompt（如《冬盡春來》→ 清新鋼琴＋春意晨光）
2. 使用 `music_generator.py`：
   ```powershell
   python ~\.claude\skills\jet-audio.cpp\scripts\music_generator.py \
       --title "<詩名>" --prompt "<意境 prompt>" \
       --lyrics "[Instrumental]" --duration 30
   ```
3. 從 `C:\App\audio.cpp-webui\output\` 複製音檔至 `assets/audio/poems/<id>.wav`
4. 檔名 `music_<日期>_<詩名>_<seed>.wav` → 重新命名為 `<id>.wav`

## 7. 視覺設計細節（暖紙手札）

- **配色**：底色 `#faf3e3` 系暖紙、文字暖墨褐 `#4a3b24`、分隔線卡其
- **字體**：標題楷體（DFKai-SB/Kaiti），內文宋體（Noto Serif TC/Songti）
- **首頁**：紙感大標題「Kelly 的詩詞」＋毛筆小印；年份紙籤導航（2014–2025），
  點選切換顯示該年詩作卡片（圖＋詩名＋一句摘錄）
- **詳情頁**：大圖置頂，詩文大字排版，下方日期、地點、寫作註記；內嵌 30 秒播放器
- **細節**：紙紋背景、毛邊卡片、朱紅印章點綴、行動裝置自適應

## 8. 流程工具（tools/，含 test/temp 標記）

- `temp_parse_poems.py`：掃描詩詞目錄、偵測編碼、轉 UTF-8、輸出 JSON
- `temp_gen_image_prompts.py`：依詩意生成 comfyui 提示詞（配合人工微調）
- `temp_gen_music_prompts.py`：依詩意生成音樂 prompt
- 一律使用 `test`/`temp` 前綴，確保使用者一眼可辨識為暫存檔
